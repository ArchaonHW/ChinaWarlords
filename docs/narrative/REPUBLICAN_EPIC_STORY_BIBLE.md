# 《MingGoRTS：民國史詩》敘事聖經

> 狀態：敘事方向草案；使用者已指定主、輔劇情優先序。歷史事件細節仍須在逐章製作時逐項查證。
>
> 本文件是遊戲敘事方向依據，不宣稱本故事已在遊戲中可遊玩。現有劇情載入器與遊戲啟動流程尚未接通，詳見「專案現況與交付順序」。

## 一句話與核心問題

以革命組織者及其後代留下的檔案為視角，走過 1894 至 1996 年的革命、建國、戰爭、遷徙與民主化。玩家面對的不只是「能否打贏」，而是「能打時誰選擇不打；戰後誰能治理；人民是否能參與決定」。

敘事主題：

- **至聖者無戰**：能以談判、疏散、倒戈或停火避免流血時，避免戰鬥本身可以是成果。
- **治平者無勝**：勝利不以佔城或殲敵計分；要看秩序、民生、權利、救援與制度能否延續。
- 歷史人物不是單一陣營的聖人或反派。玩家會看到派系分歧、政策代價、暴力與不同群體的記憶。

## 正史與輔線的優先序

### 主線：歷史編年

第一份劇情企劃決定年代、主要歷史事件、人物所處局勢及已知結果。遊戲可以用虛構角色參與局部任務，但不得把原創行動寫成改變歷史走向的原因，也不得提供推翻史實結果的正史分支。

### 輔線：民間信仰與神話寓言

第二份企劃中的城隍、狐仙、亡魂、戰神、天命三派，以及「天命歸民」意象，是角色理解戰亂、權力與責任的可選寓言層。它們可以出現在傳聞、夢境、地方信仰、手記或明確標示的架空支線；不得成為革命、戰爭或政治事件的真實成因，也不得改寫史實結局。

未來跨海峽合作、世界共和及神話結局都屬於**架空／推想尾聲**，不能當成已發生的正史。涉及兩岸人民意願、權利與安全時，不預設任何一方的政治選擇。

### 內容標籤

後續遊戲呈現必須能分辨：

- **史實**：由可靠史料支持的日期、人物、制度與結果。
- **角色觀點**：角色在特定位置、資訊與利益下的理解，不代表全體共識。
- **民間傳說**：角色或社群流傳的信仰與故事，不作為史實證據。
- **原創情節／對白**：為遊戲撰寫的虛構內容。除有明確史料來源外，不把台詞加引號冒充歷史人物原話。

## 原創人物與敘事鏡頭

- **林若衡**：輔線的虛構青年幕僚，可作為早期檔案鏈的第一位記錄者；不得取代史實人物或被寫成革命成功的關鍵原因。
- **世代接續者**：用信件、日記、口述記錄與後代整理者跨越數十年。這讓年代跨度可由普通人的經驗連起來，亦容許互相矛盾的記憶並存。
- **沈清瀾**：虛構的權利／制度觀察者，適合提出治理與自由的質疑；不要把她寫成唯一正確的歷史裁判。
- **白梨、玄戈**：狐仙與戰神等輔線角色；若出場，需使用寓言／架空標示，不能提供戰場作弊情報、改變史實或替政治暴力背書。

可使用虛構的低階組織者、醫護、地方居民、記者或後代整理者作玩家視角。真實人物只依史料出場；其觀點須置於當時脈絡中呈現。

## 第一個可交付的故事切片：《黃花崗七十二烈士》

主線企劃把黃花崗作為第一個完整腳本。這應是敘事垂直切片，而非整段戰爭系統的大改造：

1. **開場**：以 1894–1905 的組織沿革作短序，交代聯絡網、失敗經驗與行動選擇；明確區分史料摘要和虛構角色視角。
2. **局勢**：任務行動依史料校訂；用虛構基層組織者觀察部署、訊息中斷和城市居民面臨的風險。
3. **可玩目標**：傳遞訊息、維持隊伍秩序、尋找撤離路線、協助傷者及平民、保全記錄。戰役的史實結果不因玩家選擇而翻轉。
4. **輔線入口**：城隍或白梨可作為一段可略過的傳聞／夢境；關閉神話內容時，任務目標、歷史資訊和結果完全一致。
5. **結尾檔案**：分列「史實記錄」「角色證言／觀點」「原創片段」；不替真實人物編造引言，不把傷亡折算成分數或掉落。

### 切片驗收條件

- 章節年代與歷史結果由史料審核，不存在推翻正史結果的結局。
- 玩家至少能透過非戰鬥行動影響救援、秩序、證言或檔案保存。
- 神話內容可略過，且不影響模擬狀態、敵方真實資訊或戰役結果。
- 正史、角色觀點、民間傳說與原創對白在 UI／內容資料中有明確標記。
- 後續若實作版本化 JSON，沿用遊戲層 JsonValue；壞 schema 必須在修改遊戲狀態前被拒絕。
- 固定模擬仍維持 deterministic/headless；敘事顯示與檔案讀取放在模擬 tick 之外。

## 專案現況與交付順序

檢視當前 origin/main 的結果：

- Game/Shell/main.cpp 啟動時載入世界、人物、遭遇、藥材、兵法、部隊與戰場地圖，**沒有載入 ChapterLibrary 或 NarrativeLibrary**。
- assets/chapters/ 尚無章節內容；assets/narrative/core.json 只有 ch01_duanqiao 的章回套語，且其敕命／天命語氣不適合直接代表本歷史故事。
- assets/worlds/republic_fall.json 目前是開封、鄭州、黃河渡口、龍門、洛陽、潼關的抽象地圖；人物資料則是董卓、郭嘉、呂布。尚未形成 1911 年廣州的戰役內容。
- potato.chapter/1 已有章節標題、地圖、簡報及解鎖條件，但遊戲殼尚未把它接成故事流程。potato.narrative/1 主要存章回開場／評語／懸念和變體，並非完整劇情腳本格式。

因此這次先把已核定的敘事方向、正史章節骨架、支線界線與第一個可交付切片加入追蹤中的專案文件。後續建議依序：

1. **本文件**：凍結主／輔線優先序和史實標記規則。
2. **敘事內容模型與啟動流程**：先設計支援來源標籤、對白、任務目標、可選寓言內容的版本化資料，再讓 Game shell 載入；不要把新劇情塞進目前僅供章回套語使用的格式。
3. **黃花崗切片**：先完成史料清單、角色表、對話、任務目標、地圖需求及結尾檔案，再接既有 Campaign／Encounter 流程。
4. **擴展主線章節**：依章節骨架逐章製作；每輪只加入一章或一個小型可驗證功能。

本文件不改動被 .gitignore 排除的本機 _bmad-output/。合併前可再由專案維護者將相同決策同步至該本機規劃區。

## 延伸理論：策略與治平治理

兩篇新增文章的共同主張是：成熟的權力必須能採取行動，也能停止、受審查並修正；長期治理還要兼顧共同體自主、民主問責、民生保障與自願合作。完整的遊戲設計轉譯、既有 Campaign 系統對照與驗收檢查見[策略與治平治理框架](./STRATEGIC_GOVERNANCE_FRAMEWORK.md)。這些文章提供規範性設計觀點，不作為歷史資料或已驗證的數值公式。
